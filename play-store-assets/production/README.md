# Google Play phone screenshots

Four 1080 x 1920 portrait screenshots prepared on 2026-09-15 from the real
Android release captures in `../raw/`. These are refreshed store compositions,
not new emulator captures. The complete captured screen remains visible, with
no generated application UI or invented functionality.

The source is `../compositor.html` (`?mode=1` through `?mode=4`). It uses a fixed
1080 x 1920 canvas; export that complete rectangle at 1x. Feature mode remains
1024 x 500. Existing icon and feature graphic are in `../final/`.

Google Play listing order: search, playback, cinema dark, live chat.

All four images were visually reviewed and accepted by the Play Console asset
uploader. The first production release uses the existing closed-tested AAB
version 1.4.4 (code 6); the repository's planned 1.4.5 (code 7) is not uploaded.
